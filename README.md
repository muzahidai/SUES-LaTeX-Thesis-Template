# SUES-LaTeX-Thesis-Template
1. Graduation thesis template for the School of Electronic and Electrical Engineering (EEE). This is not the official template provided by the school; rather, it follows the thesis formatting guidelines and instructions provided by the school in 2026. Please check the latest instructions from the school each year and update the template accordingly.

2. Keep all figures (JPG and PDF files) in the `figures` directory.


3.Compile main.tex with XeLaTeX because the template contains Chinese characters.
